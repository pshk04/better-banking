Project Commands:


Gradle:

To run tests from root project folder:

	./gradlew test

To run as 'dev' profile:

	./gradlew bootRun --args='--spring.profiles.active=dev'



Docker:

	Starting mysql container by passing password and an option to run from any host as environment variable:

		docker run -d --name mysql-container -p 3306:3306 \
  				   -e MYSQL_ROOT_PASSWORD="root" \
  				   -e MYSQL_ROOT_HOST="%" \
  				   -e MYSQL_DATABASE=better_banking \
  				   \mysql:latest


  	Connect to Mysql DB on docker:

  		mysql -h 127.0.0.1 -u root -p
